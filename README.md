# Bibles from bible.com
SQLite bibles translations from bible.com (YouVersion) 

These DB are non aliase, and non lemmatization, so they without function fast search, by words search, and aliase search (ex. gen 1 1-5 quick search in app)

### Just pure SQLite DB file with well indexing for books, chapster, verses, and about publisher and version

#### Includes original languages short, abbreviation and long name for books and standart USFM – (Unified Standard Format Markers) english name in each Bible translation.
